# Potetobot

Potetobot ডেস্কে রাখার একটি ছোট যন্ত্র। গোল পর্দায় একটি মুখ থাকে, আর পড়ার মতো কথা এলে একটি বুদবুদ খোলে। এটি চলে Waveshare ESP32-S3-Touch-AMOLED-2.16 বোর্ডে। পর্দায় দুটি মুখ: poteto আর sunny। Windows-এর একটি ছোট প্রোগ্রাম, peer, একই USB সিরিয়াল সংযোগে ভাবের লাইন আর উত্তরের লেখা বোর্ডে পাঠায়।

ফার্মওয়্যার কণ্ঠে উত্তর দেয় না। `firmware/main`-এ অডিও আউটপুট নেই। বোর্ডে ES8311 স্পিকার আর মাইক্রোফোন আছে, এই বিল্ড দুটোই অব্যবহৃত রাখে। ভাষার মেনু নেই, ওয়াকি-টকিও নেই। peer যে শব্দ পাঠায়, সেগুলো পর্দায় আঁকা হয়।

মুখের চেহারা আগের মতোই থাকে। Poteto-র হাতে মিষ্টি আলু থাকে। Sunny-র হাতে খবরের কাগজ থাকে, চোখের উপরে সানগ্লাস থাকে।

## বোর্ড

Waveshare ESP32-S3-Touch-AMOLED-2.16 (SKU 33969) একটি ESP32-S3R8 মডিউল, 8 MB PSRAM আর 16 MB ফ্ল্যাশ সহ। প্যানেল 480 গুণ 480-এর CO5300 AMOLED, চার-লাইনের SPI-তে। স্পর্শ CST9217 (অথবা CST9220), I2C-তে: SCL হলো GPIO14, SDA হলো GPIO15, ইন্টারাপ্ট GPIO11, রিসেট GPIO40। পাওয়ার দেখে AXP2101। ব্যবহারকারীর কী GPIO18।

এই কম্পিউটারে USB Serial/JTAG পোর্ট COM5 হয়ে আসে। peer তার সাথে 115200 বডে কথা বলে। পোর্ট খোলার সময় DTR আর RTS দুটোই বন্ধ থাকে, তাই peer চালালে চিপ ডাউনলোড মোডে রিসেট হয় না।

factory অ্যাপ পার্টিশন 8388608 বাইট, `0x10000` থেকে `0x810000` পর্যন্ত। অ্যাপ ইমেজকে তার ভিতরেই আটতে হয়। বুদবুদের অক্ষর-মানচিত্র সেখানে আটে না। সেটি আলাদা ডেটা পার্টিশনে থাকে, নাম `font`।

## মুখ

Poteto-র কালো চুল, গালে হালকা লালিমা, গোল সোনালি চশমা, আর হাতে মিষ্টি আলু। Sunny-র ছোট কালো চুল, চোখের উপরে বাদামি সানগ্লাস, আর হাতে সূর্য আঁকা খবরের কাগজ। ছবির নোঙর 480 গুণ 480 ক্যানভাসে x 255, y 271। এই প্রকল্প সেই ছবি আবার আঁকে না, ফ্রেমের গতিও বদলায় না।

প্যাক করা ভাব, আর লুপের ফ্রেম হার:

| ভাব | ফ্রেম প্রতি সেকেন্ড |
| --- | --- |
| idle | 6 |
| listening | 15 |
| thinking | 12 |
| speaking | 6 |
| tilt | 6 |
| breath | 6 |
| emphasis | 6 |
| smile | 6 |

Poteto-র listening আর thinking-এ প্যাক করা ফ্রেম নেই। বোর্ড সেই দুটি বাছাই ফিরিয়ে দেয়, ACK পাঠায় না, আর যে মুখ আগে থেকে পর্দায় আছে সেটিই থাকে। Sunny-র listening আর thinking-এর ফ্রেম আছে। দুজনের কথা বলা 6 ফ্রেম প্রতি সেকেন্ডের ছোট লুপ। প্লেয়ার প্রায় প্রতি 66 মিলিসেকেন্ডে আবার আঁকে।

## SEL

বাছাইয়ের লাইন চরিত্র আর ভাবের নাম লেখে:

```
SEL v1 poteto idle
SEL v1 sunny speaking
```

ভাবের পরে মিলিসেকেন্ডে একটি ঐচ্ছিক সময় থাকতে পারে। বোর্ড এক লাইনে উত্তর দেয়:

```
ACK poteto idle
```

peer নিজের স্ট্যান্ডার্ড আউটপুটে `poteto idle` ছাপে, আর আসল লাইনটি সিরিয়াল পোর্টে এগিয়ে দেয়। `grok-bot` আর `orca` দুজনেই এটা করে। পড়ার লুপ একটিই।

## SAY আর বুদবুদ

উত্তরের লেখা একই সংযোগের দ্বিতীয় লাইনে যায়:

```
SAY v1 thinking still working
SAY v1 answer hello potato
```

`thinking` সেই লাইন, যখন বট তখনও কাজ করছে। `answer` সেই লাইন, যখন উত্তর এসে গেছে। লাইনের বাকি অংশ UTF-8 লেখা, 480 বাইট পর্যন্ত রাখা হয়। বোর্ড উত্তর দেয়:

```
ACK say thinking
ACK say answer
```

`thinking` বা `answer` ছাড়া অন্য ধাপ ফিরিয়ে দেওয়া হয়। `SAY` লাইন মুখ বাছাইয়ের লাইন নয়।

দুটি ধাপই প্যানেলে বুদবুদ খোলে। আয়তক্ষেত্র x = 12, y = 356, প্রস্থ 456, উচ্চতা 112। এটি চোখের নিচে, সানগ্লাসের নিচে। মিষ্টি আলুর উপরের অংশ, আর খবরের কাগজের সূর্য, বুদবুদের উপরে পুরো উজ্জ্বলতায় থাকে। বুদবুদের নিচের পিক্সেল প্রায় এক-চতুর্থাংশ উজ্জ্বলতায় ম্লান হয়। সেগুলো মুছে ফেলা হয় না, বুদবুদের লেজও নেই। ব্যাসার্ধ 14-এর সাদা গোল বর্ডার ম্লান জায়গাটিকে ঘিরে রাখে। ভাবনার লেখা নরম সাদায় আঁকা হয়। উত্তরের লেখা সাদায় আঁকা হয়।

বুদবুদে প্রায় চার লাইন ধরে। লম্বা লেখা ফাঁকা জায়গায় ভেঙে যায়। বোর্ড শেষ আটটি বার্তা রাখে। নতুন বার্তা সবচেয়ে নতুন লাইনে চলে যায়। আগের লাইন পড়তে আঙুল বুদবুদের ভিতরে রেখে টানো। আঙুল উপরে তুললে নিচের লেখা বেরিয়ে আসে। স্ক্রল সবচেয়ে পুরনো লাইনে আর সবচেয়ে নতুন লাইনে থেমে যায়। বুদবুদের বাইরে থেকে শুরু হওয়া টান স্ক্রল করে না।

বুদবুদ ডিকোড হওয়া মুখের উপরে আঁকা হয়, তারপর ফ্রেম প্যানেলে যায়। মুখ, মিষ্টি আলু, খবরের কাগজ আর সানগ্লাস আগের সেই ছবিই।

## অক্ষর-মানচিত্র

factory ইমেজে প্রায় পনেরো কিলোবাইট ফাঁকা থাকে, বহুভাষার ফন্টের জন্য তা যথেষ্ট নয়। মানচিত্র GNU Unifont 16.0.04, factory ইমেজের বাইরে রাখা।

`tools/gen_bubble_font.py` লেখে `firmware/font/bubble_font.bin`। এই গাছের ফাইল 1325432 বাইট। পার্টিশন `firmware/partitions.csv`-তে লেখা:

```
font, data, 0x40, 0x810000, 0x200000
```

এটি `0x810000` থেকে শুরু হওয়া 2097152 বাইট, factory অ্যাপের ঠিক পরে। ফার্মওয়্যার বুটে সেই পার্টিশন ম্যাপ করে। ম্যাজিক না থাকলে ইংরেজি অক্ষর অ্যাপের ভিতরের ছোট Unifont ছক থেকে আঁকা হয়, অন্য লিপি আঁকা হয় না। স্বীকৃতি `firmware/font/LICENSE.txt`-তে। প্রকাশ করার ফাইলে Windows ফন্ট র‍্যাস্টার করো না। `tools/gen_font.py` সেই ফন্ট নয় যা এই বোর্ড পড়ে।

## ড্রাইভার

`host/peer_main.c` ই peer। ডিফল্ট ড্রাইভার `grok-bot`। সে `%APPDATA%\Grok Bot\desktop-status.json` পড়ে, এবং তখনই এগোয় যখন `signedIn` সত্যি হয় আর লেখা প্রসেস নম্বর তখনও জীবিত থাকে।

`orca` চলমান `Orca.exe` খোঁজে। সে Grok Bot-এর অবস্থার ফাইল পড়ে না, Grok লগইনও চায় না।

```
potetobot-peer.exe
potetobot-peer.exe --driver grok-bot
potetobot-peer.exe --driver orca
```

`POTETOBOT_DRIVER` একই নাম বেছে নেয়। দুটোই থাকলে `--driver` জেতে। `POTETOBOT_PORT` বোর্ড বেছে নেয়, যেমন `COM5`। দুই ড্রাইভারই স্ট্যান্ডার্ড ইনপুট পড়ে। `SEL` লাইন মুখ বদলায়। `SAY` লাইন যেমন লেখা তেমন এগিয়ে যায়, তাই যেকোনো ড্রাইভার ভাবনার লেখা বা উত্তরের লেখা প্যানেলে তুলতে পারে।

peer বানাও রিপোজিটরির মূল থেকে Visual Studio-র x64 টুল দিয়ে:

```
cl /nologo /O2 /I firmware\main /Fe:host\build\potetobot-peer.exe host\peer_main.c firmware\main\schedule.c firmware\main\frame_table.c firmware\main\say.c
```

`host/build/test_schedule.exe` ফ্রেম লুপ আর `SAY` পার্সার পরীক্ষা করে। আর্গুমেন্ট রিপোজিটরির মূল। `tests/test_peer.py`-এর জন্য সাইন-ইন করা Grok Bot লাগে। `tests/test_peer_orca.py`-এর জন্য `Orca.exe` লাগে।

## ফার্মওয়্যার বানানো

ESP-IDF 5.5 ব্যবহার করো। PowerShell-এ:

```
. C:\Esp\esp-idf\export.ps1
cd firmware
idf.py build
```

মুখের প্যাক আগে থেকেই `firmware/main/frames.bin`। সাধারণ বিল্ড সেই ফাইল বসিয়ে দেয়। চরিত্র আবার আঁকে না। অ্যাপ ইমেজ `firmware/build/potetobot.bin`। 8388608 বাইটের বেশি হলে ফ্ল্যাশ কোরো না।

## COM5-এ ফ্ল্যাশ

`firmware\build` থেকে, ESP-IDF-এর Python দিয়ে:

```
python -m esptool --chip esp32s3 -p COM5 -b 460800 --before default_reset --after hard_reset write_flash --flash_mode dio --flash_size 16MB --flash_freq 80m 0x0 bootloader\bootloader.bin 0x8000 partition_table\partition-table.bin 0x10000 potetobot.bin 0x810000 ..\font\bubble_font.bin
```

বুটলোডার, পার্টিশন টেবিল আর অ্যাপ সেই তিনটি ইমেজ। `bubble_font.bin` লেখা হয় `0x810000`-এ, সেটি `font` পার্টিশন, factory অ্যাপের অংশ নয়। হার্ড রিসেটের পরে, লগে অ্যাপ `app_main` থেকে ফেরার কথা না আসা পর্যন্ত অপেক্ষা করো, তারপর `SEL` বা `SAY` পাঠাও।
